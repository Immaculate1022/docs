## How to Use This Repository

Use this repository as the cross-project index, not as a replacement for each project’s README. Before relying on an implementation claim, check the project’s current README, status file, release information, and examples. Experimental research and prototypes should be treated as exploratory unless a repository explicitly documents a tested release or reproducible benchmark.
